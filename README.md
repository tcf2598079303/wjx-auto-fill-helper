# 问卷星自动填写助手

**WJX Auto Fill Helper** 是一个基于 Tampermonkey（油猴）的用户脚本项目，用于辅助识别问卷星页面中的题目，并根据用户预先配置的关键词与答案自动填写匹配的题目。

项目使用 JavaScript 编写，适用于支持的问卷星网页，旨在减少重复填写操作，并提供简单的规则管理和识别结果查看功能。

## ✨ 功能特点

- **自动识别题目**：扫描问卷页面中的题干、输入框、单选框、多选框和下拉框。
- **关键词匹配**：根据预设题目关键词查找对应题目。
- **自动填写答案**：对成功匹配的题目尝试填写预设答案。
- **规则管理**：支持添加、删除和保存题目匹配规则。
- **本地保存**：使用浏览器 `localStorage` 保存预设规则。
- **动态页面扫描**：监听页面变化，并在题目动态加载后重新扫描。
- **结果展示**：显示题目识别结果、匹配答案和填写状态。
- **规则导出**：支持将预设规则导出为 JSON 文件。

## 📦 安装方法

### 1. 安装 Tampermonkey

在浏览器中安装 Tampermonkey 扩展：

https://www.tampermonkey.net/

### 2. 安装用户脚本

1. 打开浏览器中的 Tampermonkey 管理面板。
2. 创建一个新的用户脚本。
3. 将项目中的完整 `.user.js` 脚本代码复制到编辑器。
4. 保存并启用脚本。
5. 打开支持的问卷星页面并刷新。
6. 检查页面右上角是否出现“问卷星自动填写助手”面板。

## ⚙️ 使用方法

### 1. 添加预设规则

在助手面板中填写：

- **题目关键词**：用于识别目标题目的文字。
- **预设答案**：希望填写的答案。

例如：

| 题目关键词 | 预设答案 |
|---|---|
| 姓名 | 阿迪斯 |
| 手机号码 | 15865442502 |
| 你喜欢的颜色 | 蓝色 |

以上仅为配置示例，请根据实际情况修改。

### 2. 扫描并填写

添加规则后，可以使用面板中的“立即扫描填写”功能。

脚本会尝试识别页面题目，并将预设答案填写到匹配的输入框或选项中。

### 3. 保存与导出规则

规则保存在当前浏览器的本地存储中。需要备份时，可以使用面板中的规则导出功能，生成 JSON 文件。

请注意：清除浏览器网站数据可能导致本地规则丢失，建议定期备份。

## 🌐 适用范围

脚本通过用户脚本元数据中的 `@match` 规则限定运行的网站。实际支持的网站及页面类型，以脚本文件中的配置为准。

由于问卷星不同页面的 DOM 结构可能存在差异，题目识别和答案匹配效果需要在具体页面中测试。

## ⚠️ 注意事项

1. **匹配结果需要核对**：题干相似、关键词重复或页面结构特殊时，可能出现匹配错误。
2. **不要盲目提交**：提交前应检查填写结果，确认答案准确。
3. **遵守平台规则**：仅在获得授权且符合问卷发布者要求的情况下使用。
4. **保护个人信息**：不要将真实姓名、手机号、问卷答案或其他敏感信息上传到公开仓库。
5. **网站校验仍然有效**：脚本不会保证提交成功，也不能替代问卷星自身的校验流程。
6. **浏览器兼容性**：建议使用支持 Tampermonkey 的现代浏览器。

## 🔧 故障排查

### 助手面板没有出现

- 确认 Tampermonkey 已启用。
- 确认用户脚本已保存。
- 检查当前网址是否符合脚本的 `@match` 配置。
- 刷新页面后检查浏览器开发者工具 Console 中的错误信息。

### 答案匹配错误

- 检查关键词是否能唯一对应目标题目。
- 避免多个规则使用相同或过于宽泛的关键词。
- 检查识别结果中显示的题干是否正确。
- 对不同题型分别测试，确认填写结果符合预期。

### 规则没有保存

- 确认浏览器允许网站使用本地存储。
- 检查浏览器是否清理了网站数据。
- 建议定期导出规则文件进行备份。
